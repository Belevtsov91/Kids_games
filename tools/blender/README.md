# 3D-модели из Blender

Сцены оболочки, которые выглядят «плюшево» и объёмно, собираются скриптами Blender и кладутся в репозиторий готовыми файлами `.glb`.
Сайту Blender не нужен: он только загружает готовый файл.

## Что здесь

| Файл | Что делает |
| --- | --- |
| `build_wake.py` | Собирает сцену «Мишка просыпается» и пишет `shell/src/wake/scene/wake.glb` |
| `bear.py` | Плюшевый мишка в колпаке. Суставы названы как поля `BearRig` в `shell/src/wake/scene/bear.ts` |
| `bed.py` | Кровать, стёганое одеяло, тумбочка с лампой, коврик, тапочки |
| `island.py` | Остров: трава, земля, скала, деревья, цветы, грибы, игрушки |
| `lib.py`, `paint.py` | Помощники: формы, сглаживание, цвет по вершинам, запекание мягких теней |

## Как пересобрать

```bash
python3 -m venv .venv-blender
.venv-blender/bin/pip install bpy          # Blender как модуль Python, около 430 МБ
.venv-blender/bin/python tools/blender/build_wake.py --preview preview.png
```

Нужен Node.js: в конце скрипт сжимает модель через `npx @gltf-transform/cli meshopt` (примерно с 3 МБ до 0,8 МБ).
Ключ `--preview` дополнительно рисует пробный кадр, чтобы посмотреть результат без сайта.

## Как это устроено

- Геометрия пишется в координатах three.js (Y вверх), в Blender переводится в самом конце — числа совпадают с кодом сцены.
- Текстур нет: цвет и запечённые мягкие тени (AO) лежат прямо в вершинах. Поэтому файл маленький, а свет в сцене остаётся живым (ночь → рассвет).
- Подвижные части (голова, лапы, глаза, колпак, одеяло) — отдельные узлы с точкой опоры в суставе. Позы задаёт код: `shell/src/wake/scene/pose.ts`.
- Если модель не загрузилась за 4 секунды, сцена показывает запасного мишку из простых фигур (`buildPlainSet` в `set.ts`).
