# Interact Games

**Русский** · [Українська](README.uk.md) · [Română](README.ro.md) · [English](README.en.md)

Игры для детей 3–15 лет и кабинет для взрослых. Сайт на четырёх языках: русский, украинский, румынский, английский. pnpm-воркспейс: каждая игра — отдельный пакет со своими зависимостями, кодом, сервером и тестами. Общие только оболочка (`shell`) и маленькая платформа.

## Что умеет сайт

- **Вход родителя** и восстановление пароля по почте. Новый аккаунт проходит «настройку за минуту»: ребёнок, время в день, PIN.
- **Профили детей.** Ребёнок выбирает себя, а дашборд показывает игры по его возрасту, «Продолжить», план на сегодня от взрослого, мишку Тёпу, сезонное оформление и голосовой привет взрослого.
- **Режим малыша** (до 5 лет или включает взрослый): без лишних кнопок, а выход из игры — удержанием кнопки 2 секунды. Сменить профиль или открыть кабинет без взрослого нельзя.
- **Время:** дневной лимит, тихие часы и перерывы. Ребёнок может попросить ещё времени, а взрослый ответит в кабинете, по кнопке из письма или через помощника семьи. За 2 минуты до конца игра узнаёт об этом и заканчивает мягко.
- **Успехи:** навыки (счёт, цвета, фигуры, память…), уровни и наклейки. Ребёнок видит альбом наклеек, взрослый — навыки по каждому ребёнку.
- **Кабинет родителя** `/parent` (вход задачей + PIN): обзор, профиль ребёнка, время, доступ к играм, статистика, навыки, удобство (громкость, меньше движения, крупные кнопки), галерея рисунков, план дня, просьбы, помощники семьи (бабушка ответит по своей ссылке), письма и недельный отчёт, выгрузка данных, удаление аккаунта.
- **Другие страницы:** каталог игр с карточками (что развивает, как играть вместе), «Что нового», экран «нет сети», страница 404.

Платных функций пока нет.

## Стек

- **shell:** TypeScript, Vite, React, react-router, PWA (vite-plugin-pwa).
- **игры:** что угодно на выбор игры: чистый DOM и Canvas, SVG, React, PixiJS + Howler (рисовалка), matter-js (космический садовник), Three.js + React Three Fiber + drei + Rapier (3D-игры). Голос — Web Speech, звуки — Web Audio.
- **сервер:** Node 24, TypeScript, Fastify (запуск через tsx). Данные — в Supabase (Postgres); у каждой игры свои таблицы. Почта — Brevo.
- **тесты:** Vitest (юнит и API), Playwright (e2e, десктоп и телефон).

## Запуск

Нужен Node 24+. pnpm идёт через corepack, версия закреплена в `package.json`.

```bash
corepack pnpm install     # один раз и после добавления игры
corepack pnpm dev         # shell (http://localhost:5173) + сервер (http://localhost:3000)
corepack pnpm dev:shell   # только клиент
corepack pnpm dev:server  # только API
corepack pnpm lint        # границы (игры не импортируют друг друга) и размер файлов (≤ 200 строк)
corepack pnpm typecheck   # типы во всех пакетах
corepack pnpm test        # юнит- и API-тесты всех пакетов
corepack pnpm test:e2e    # вход, настройка, меню → игра → выход для каждой игры (Playwright)
corepack pnpm build       # lint + типы + сборка shell
```

Перед первым `test:e2e` один раз: `corepack pnpm --filter @ig/shell exec playwright install chromium`.

В dev Vite проксирует `/api/*` на `http://localhost:3000`. Настройки сервера: скопируйте `platform/server/.env.example` в `platform/server/.env`.

### База данных

Создайте проект Supabase и заполните в `.env` `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` и `SESSION_ENCRYPTION_KEY`. Без них сервер работает, но вход отвечает 503, а API игр — 401 (нет сессии).

Миграции платформы (`platform/server/migrations/001–006`) и всех игр собираются в один скрипт:

```bash
node tools/db-sql.mjs > all.sql
```

Содержимое `all.sql` выполняется в Supabase → SQL Editor. Скрипт идемпотентный (`create … if not exists`): после новой миграции или игры его можно просто выполнить ещё раз. Без миграций 004 и 005 не работают навыки, наклейки, облачные сохранения, удобство, помощники, письма и план дня; без 006 — разовая смена профиля по PIN взрослого.

### Почта

Письма (сброс пароля, просьба ребёнка о времени с кнопками «Да/Нет», недельный отчёт) отправляются через **Brevo**. В `platform/server/.env` задайте `MAIL_FROM_EMAIL` (отправитель, подтверждённый в Brevo → Senders) и один из способов отправки: SMTP (`SMTP_USER` вида `xxxx@smtp-brevo.com` и `SMTP_PASSWORD` — ключ `xsmtpsib-…`) или HTTP API (`BREVO_API_KEY` — ключ `xkeysib-…`). `APP_URL` — адрес сайта для ссылок в письмах. Ключи держим только в `.env` и в переменных окружения хостинга, в git не кладём.

Без почты в dev сервер пишет ссылку для сброса в лог, а в проде (`NODE_ENV=production`) отвечает 503. Ссылка сброса одноразовая и живёт 30 минут, кнопки в письме о просьбе — 24 часа. Недельный отчёт отправляет фоновая задача настоящего сервера (`server.ts`), в тестах она не запускается.

### Продакшен

Клиент — Vercel (`shell/vercel.json` проксирует `/api` на сервер), сервер — Render. Переменные сервера в проде:

- `NODE_ENV=production`, `COOKIE_SECURE=true`, `APP_URL=https://ваш-домен`.
- `CORS_ORIGIN` — один адрес или список через запятую (например, домен и превью Vercel).
- `TRUST_PROXY` — сколько прокси перед сервером (по умолчанию 2: Vercel и Render). От него зависят IP в лимитах запросов.
- `CRON_SECRET` — включает `POST /api/jobs/hourly` (недельные отчёты) и `/api/jobs/daily` (уборка) с заголовком `x-cron-secret`. Нужен, если бесплатный Render усыпляет сервер: тогда внутренние таймеры не срабатывают, и их будит внешний cron.
- `VITE_API_URL` на Vercel не задаём: запросы идут на тот же домен через прокси, иначе cookie сессии станет сторонней.

Сервер при старте пишет в лог, каких настроек не хватает.

### Внутри игры

| Папка | Что там |

| `ui/` | DOM или React-компоненты интерфейса |
| `scene/`, `scenes/`, `render/` | 3D-сцена, сцены 2D-игры или отрисовка на Canvas |
| `audio/` | звуки и речь |
| `api/`, `storage/` | сохранение: сервер игры, облако платформы или браузер |

Файл — одна ответственность и не больше 200 строк (проверяет `corepack pnpm lint`; README и другие `.md` не проверяются). Крупный модуль становится папкой с `index.ts`.

## SDK игры

Игра получает от оболочки только SDK:

| Поле | Что это |
|---|---|
| `manifest`, `profile`, `locale` | манифест, ребёнок (или `null`), язык сайта |
| `api` | запросы только в свой префикс `/api/games/<id>` |
| `storage` | localStorage с ключами игры и ребёнка, копия в облаке платформы |
| `cloud` | сохранения на сервере платформы по ребёнку (для игр без своего сервера), до 64 КБ на ключ |
| `audio` | общий выключатель звука |
| `progress` | `level()`, `skill(skill, ok)`, `sticker(id)` — успехи для альбома и кабинета |
| `time` | сколько осталось и `onEnding()` за 2 минуты до конца |
| `comfort` | громкость музыки и эффектов, меньше движения, крупные кнопки, режим малыша |
| `exit()` | вернуться в меню |

## Правила

1. Игра не импортирует другую игру, `shell` или `@ig/server`. С платформой связь только через `@ig/sdk`. Это проверяет `corepack pnpm lint`.
2. Shell и сервер не знают игры по именам: каталог собирается из манифестов. Добавили папку — игра появилась в меню и в API. Удалили — пропала, остальное работает.
3. `id` в манифесте совпадает с именем папки. Битый манифест не роняет каталог: игра пропускается, ошибка пишется в лог. Навыки и наклейки в манифесте проверяются.
4. Код, который нужен только одной игре, живёт в её папке. В `platform/` попадает только то, что нужно всем.
5. Сервер игры узнаёт, чьи данные, только из сессии: `childIdOf(req)` / `requireChild` из `@ig/sdk/server`. `profileId` из запроса не принимается.
6. У каждой игры свои таблицы `ig_game_<id>_*` (дефисы в id → `_`). Клиент `opts.db` бросает ошибку при обращении к чужой таблице, а lint проверяет имена таблиц. Единственная ссылка наружу — `child_id → ig_children(id) on delete cascade`.
7. Новые таблицы платформы — только новой миграцией (`007_…`), потом пересобрать `all.sql`.


Шаблон — холст без зависимостей. Движок добавляется в `package.json` самой игры. Ненужную папку `server/` можно удалить. Не забудьте названия на 4 языках, навыки, наклейки и обложку `assets/cover.webp`.

## API

Платформа (все пути под `/api`):

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/health` | проверка живости |
| POST | `/auth/register`, `/auth/login`, `/auth/logout` | вход родителя; сессия — httpOnly-cookie |
| POST | `/auth/forgot`, `/auth/reset/check`, `/auth/reset` | сброс пароля по письму |
| GET | `/auth/me` | родитель, его дети и выбранный ребёнок |
| POST, PUT | `/children`, `/children/active` | новый профиль, выбрать, кто играет (при лимите — только со взрослым) |
| GET | `/games`, `/games/:id` | каталог игр из манифестов |
| GET, POST | `/kid/status`, `/kid/beat`, `/kid/requests`, `/kid/stats` | время, пульс игры, просьбы, статистика |
| POST, GET | `/kid/progress`, `/kid/stickers`, `/kid/stickers/seen` | успехи и альбом наклеек |
| GET, PUT | `/kid/cloud/:gameId/:key` | облачные сохранения игры (`null` удаляет ключ) |
| DELETE | `/auth/account` | удалить аккаунт: открытый кабинет и пароль |
| POST | `/jobs/hourly`, `/jobs/daily` | недельные отчёты и уборка для внешнего cron, заголовок `x-cron-secret` |
| POST | `/errors` | отчёт о падении игры |
| POST | `/answer`, `/helper`, `/helper/answer` | ответ на просьбу по ссылке из письма или от помощника |
| * | `/parent/*` | кабинет: вход, обзор, дети, навыки, просьбы, помощники, письма, план дня, PIN, аккаунт, `/setup`, `/export` |

Игры — каждая под своим префиксом `/api/games/<id>`, данные выбранного ребёнка из сессии (без него — 401):

| Игра | Пути |
|---|---|
| drawing | GET/POST `/drawings`, GET/DELETE `/drawings/:id`; для кабинета `/parent/:childId[/:id]` |
| animal-orchestra | GET/POST `/melodies`, DELETE `/melodies/:id` |
| island-builder | GET/POST/DELETE `/island` |
| letter-eater | GET/POST `/progress` |
| space-gardener | GET/POST `/progress` |
| who-lives-where | GET/POST `/progress` |
| moon-valley | GET/POST/DELETE `/save` |

## Данные в БД

Платформа: родители и сессии, дети и их настройки (время, удобство, план дня), время игры, просьбы, события успехов (`ig_play_events`), наклейки (`ig_stickers`), облачные сохранения (`ig_cloud_saves`), помощники семьи (`ig_helpers`).

| Игра | Таблица | Что в строке |
|---|---|---|
| drawing | `ig_game_drawing_drawings` | рисунок: название, PNG (data URL) |
| animal-orchestra | `ig_game_animal_orchestra_melodies` | мелодия: название, ноты (jsonb); не больше 30 на ребёнка |
| island-builder | `ig_game_island_builder_islands` | остров ребёнка (jsonb), один на ребёнка |
| letter-eater | `ig_game_letter_eater_progress` | звёзды по уровням (smallint[]) |
| space-gardener | `ig_game_space_gardener_levels` | лучшие звёзды за один уровень |
| who-lives-where | `ig_game_who_lives_where_progress` | уровень и найденные звери |
| moon-valley | `ig_game_moon_valley_saves` | состояние долины (jsonb), одно на ребёнка |

Все таблицы закрыты: RLS включён, политик нет, права у `anon`/`authenticated` отозваны. Читает и пишет только сервер с секретным ключом. Репозиторий игры работает с БД, когда платформа передала `opts.db`, и с памятью процесса без неё (тесты, запуск без Supabase).
