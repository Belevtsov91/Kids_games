# Хранители Лунной Долины

3D-приключение для детей 7–15 лет: сад, питомцы, жители с квестами, теневые слаймы и Грибной король.
Three.js + React Three Fiber + drei + Rapier. Сохранение — на сервере игры (`/api/games/moon-valley/save`).

## Где что лежит

```
src/
  index.tsx                 вход: defineGame → монтирует <MoonValley/>
  app/                      контроллер и React-хуки, связывают правила, сцену и интерфейс
    MoonValley.tsx          собирает заставку, мир и интерфейс
    runtime.ts              живое состояние мира на каждый кадр (ввод, герой, камера, сердечки)
    interact.ts             что делает кнопка «действие» для каждого вида цели (без React)
    useInteract.ts          связывает interact.ts с экраном: диалог, анимации жителей и питомцев
    useCombat.ts            жезл, очищение слаймов, урон и обморок, Грибной король, сердечки
    useValleySave.ts        загрузка и сохранение состояния
    useValleyAudio.ts       музыка и звуки, общий выключатель звука
    useToasts.ts            всплывающие сообщения
    useLevelUps.ts          новый уровень и питомцы, которые вышли из тумана
    actionLabel.ts          подпись на кнопке действия
    controls.ts             клавиатура, мышь, тач
    pause.ts                пауза от оболочки
  game/                     правила и данные без React, DOM и 3D — их покрывают юнит-тесты
    valley/                 состояние, баланс, сохранение, действия игрока (index.ts — вход)
    quests.ts               цепочка квестов и разговоры с жителями
    world/                  карта: остров, дома, жители, кристаллы, слаймы, генерация леса и травы
  scene/                    3D (всё внутри холста)
    World.tsx               холст three.js; Scene.tsx — что на нём
    environment/            небо, солнце, земля, трава, ветер, облака, пост-обработка
    village/                пейзаж (дома, лес, декор, забор) и места (сад, теплица, кристаллы, сундуки)
    characters/             питомцы, жители, олени, слаймы, Грибной король; hero/ — герой и камера
    physics/                коллайдеры Rapier
    targeting/              поиск цели рядом с героем и подсветка под ней
    models/                 загрузка .glb, персонажи с анимациями, инстансинг
  ui/                       интерфейс поверх 3D
    Intro.tsx               заставка
    hud/                    верхняя панель, квесты и журнал, сообщения, кнопки и джойстик, загрузка
  audio/                    музыка и звуковые эффекты
  i18n/                     тексты: ru, uk, ro, en
  styles/                   CSS; index.css подключает части по порядку (hud/ — по частям экрана)
server/                     Fastify-плагин игры: GET/POST/DELETE /save, таблица ig_game_moon_valley_saves
tests/                      правила, квесты, сервер, манифест
assets/                     модели, звуки, картинки
```

## Как связано

- `game/` ничего не знает про React и 3D: функции берут состояние и возвращают новое.
- `app/` держит состояние (`useValleySave`) и передаёт его в `scene/World` и `ui/hud`.
- Сцена и интерфейс общаются через `runtime` (ввод, позиция героя, текущая цель) без лишних перерисовок React.
