# Считай и играй / Лічи та грай / Numără și joacă / Count & play

Изолированная игра для детей 3–8 лет. Автоматически подключается к shell через manifest.ts.

## Возможности

- Шесть режимов: совместный счёт, кормление, сопоставление количества и числа, последовательности, сравнение групп, сложение и вычитание.
- Три темы: ферма, лес, море. Диапазоны: до 5, 10, 20. Пять заданий в каждой сессии.
- Четыре языка интерфейса и отдельно выбираемый язык речи: uk, ru, ro, en.
- Правильный ответ с первой попытки даёт звезду. После ошибки можно пробовать снова без ограничения времени.
- Лучший результат сохраняется отдельно для профиля, языка, темы, диапазона и режима через sdk.storage. Это локальное сохранение на устройстве, без синхронизации с сервером.
- Озвучка: SpeechSynthesis с проверкой наличия нужного голоса. Если голос отсутствует, показано сообщение; чужой язык автоматически не подставляется. Это системная синтезированная речь, а не студийные записи. У некоторых системных голосов речь требует подключения к сети.
- Собственные короткие музыкальные награды Web Audio. Пауза/выход отменяют речь, останавливают звук и освобождают ресурсы.

## Структура

- src/app/CountingGame.ts — контроллер: экраны, обработка нажатий, перерисовка.
- src/app/prompts.ts — текст озвучки задания и разбор настроек на главном экране.
- src/app/savedState.ts — настройки и рекорды в sdk.storage (отдельно для каждого профиля).
- src/game/logic.ts — независимый генератор заданий.
- src/game/Session.ts — сессия из пяти заданий: ответы, звёзды за первую попытку.
- src/game/themes.ts — темы, значки режимов, длина сессии.
- src/i18n/ — тексты по языкам (words/uk.ts, ru.ts, ro.ts, en.ts) и названия чисел.
- src/ui/ — HTML-шаблоны экранов: главный, задание, итог, общая рамка.
- src/audio/CountingAudio.ts — речь, mute и награды.
- src/styles/ — стили в области .counting-game по экранам, адаптация телефона.
- tests/logic.test.ts — диапазоны, ответы, варианты, локализация, правила сессии.

Новых внешних runtime-зависимостей нет. Интернет-ассеты, трекеры и внешние ссылки не используются. Иллюстрации предметов используют системные emoji.
