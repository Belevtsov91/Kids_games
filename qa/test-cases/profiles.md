# Профили детей: «Кто играет?» `/children` и кабинет `/parent`

Логика профилей от 2026-11-13 (миграция 007). Автотесты оболочки: `shell/e2e/profiles.spec.ts`; правила сервера без БД: `platform/server/tests/profiles.test.ts`.
Кейсы с пометкой «руками» требуют настоящего сервера и базы с выполненным `all.sql`.

| ID | Приоритет | Кейс | Шаги | Ожидаемый результат | Авто |
| --- | --- | --- | --- | --- | --- |
| K1 | Высокий | Новый профиль только со взрослым | В семье уже есть ребёнок. «Кто играет?» → «Добавить» → имя → «Готово» | Сервер отвечает 423 `create`, экран «Добавить новый профиль может только взрослый»; запрос один, с `rules: true` и `activate: true` | да |
| K2 | Средний | Месяц рождения вместо возраста | В форме выбрать месяц рождения, снять галочку правил | В запросе `birthMonth`, нет `age`, `rules: false`; кнопки возраста неактивны | да |
| K3 | Высокий | Защищённый профиль | В кабинете включить «Вход только со взрослым» у старшего; выбрать его на «Кто играет?» | На карточке замок; без задачи и PIN профиль не открывается (423 `locked`) | да |
| K4 | Высокий | «Кто играет?» после перерыва | Детей двое, в выбранном профиле не играли больше 4 часов, открыть сайт | Вместо игр открывается «Кто играет?»; выбор того же профиля проходит без взрослого | да |
| K5 | Высокий | Первый профиль без взрослого | Новый аккаунт → настройка за минуту | Первый ребёнок создаётся без задачи для взрослых | да (сервер: `switchReason`) |
| K6 | Высокий | Правила по возрасту | Создать профиль 4 лет с галочкой правил; открыть «Время» в кабинете | 40 мин в будни, 60 в выходные, тихие часы 20:00–07:00, перерыв каждые 20 минут | да (сервер: `defaultRules`), руками (запись в БД) |
| K7 | Высокий | Пароль вместо одной задачи | PIN не задан, ребёнку 7 лет или больше; открыть кабинет | После задачи кабинет просит пароль аккаунта; с PIN — как раньше | да (сервер: `needsPassword`), руками |
| K8 | Средний | Выход только со взрослым | Включить «Выход только со взрослым»; на «Кто играет?» выбрать другого ребёнка | 423 `exit`; после перерыва сайт не спрашивает «кто играет?» | да (сервер), руками |
| K9 | Средний | Лимит на каждый день | «Время» → «Свой лимит на каждый день», суббота 0, понедельник 30 минут | В субботу лимита нет, в понедельник таймер на 30 минут | да (сервер: `dayLimit`), руками |
| K10 | Высокий | Корзина профилей | Удалить профиль; «Дети» → «Корзина» → «Вернуть» | Профиль пропал с «Кто играет?», через «Вернуть» вернулся со всеми сохранениями | руками |
| K11 | Средний | Стереть сейчас и выгрузка ребёнка | В корзине «Скачать данные ребёнка», затем «Стереть сейчас» дважды | Скачался JSON только этого ребёнка; профиль стёрт, вернуть нельзя | руками |
| K12 | Средний | Помощник для выбранных детей | «Семья» → помощник только для одного ребёнка; открыть его ссылку | Помощник видит просьбы только этого ребёнка и не может ответить на чужую | да (сервер: `helperSees`), руками |
| K13 | Средний | Срок хранения | Аккаунт без входа 700 дней → ежедневная чистка | Уходит письмо; удаление только через 30 дней после письма; вход отменяет удаление | да (сервер: `inactiveStep`), руками (письмо) |
| K14 | Низкий | Согласие при регистрации | Зарегистрироваться | В `ig_parents` записаны `consent_at` и `policy_version`; они есть в выгрузке данных | руками |
