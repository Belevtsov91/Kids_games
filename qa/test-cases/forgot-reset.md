# «Забыли пароль?» `/forgot` и страница из письма `/reset`

Автотесты: `shell/e2e/recover.spec.ts`. F7 — только вручную.

| ID | Приоритет | Кейс | Шаги | Ожидаемый результат | Авто |
| --- | --- | --- | --- | --- | --- |
| F1 | Средний | Почта переносится со входа | На `/login` ввести почту, нажать «Забыли пароль?» | На `/forgot` почта уже введена | да |
| F2 | Средний | Неверная почта | `bad` | «В адресе не хватает символа @», запрос не уходит | да |
| F3 | Высокий | Письмо отправлено | Ввести почту, «Прислать письмо» | «Письмо улетело!», текст не подтверждает, что аккаунт есть; на сервер уходит `{ email, locale }`; «Отправить ещё раз» возвращает форму | да |
| F4 | Средний | Слишком много писем | Сервер отвечает 429 | «Слишком много попыток. Подождите немного.» | да |
| F5 | Средний | Ссылка устарела | `/reset#<чужой токен>` | «Ссылка устарела», кнопка «Получить новую ссылку» ведёт на `/forgot` | да |
| F6 | Низкий | Нет ссылки | `/reset` без `#токена` | «Здесь нет ссылки», а не «устарела» | да |
| F7 | Высокий | Настоящее письмо | Локальный сервер с Brevo, адрес существующего аккаунта | Письмо приходит, ссылка открывает `/reset`, новый пароль подходит | нет, вручную |
| F8 | Средний | Простой пароль по ссылке | Живая ссылка, пароль `abcdefgh1` | «Выполните ещё одно правило…», запрос не уходит, ссылка не сгорает | да |
| F9 | Высокий | Новый пароль сохранён | Живая ссылка, хороший пароль | Токен убран из адресной строки, «Пароль обновлён!», вход и переход в игры | да |
